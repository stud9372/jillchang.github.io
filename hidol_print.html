核心設計觀
「平台本身是底色，最精彩的永遠是 IP 與粉絲之間的故事。」
從需求金字塔出發，找到粉絲真正需要的是「懂我熱愛的地方」—— 與同溫層的連結感、被 IP 看見的距離感。這個洞察定義整個視覺方向：深色底調讓每個粉絲團發展截然不同的風格，平台退居底色、讓 IP 發光。
視覺系統 · 透明度色階
粉色 #FF3B80 — IP 發文、心動互動
紫色 #7B5FE0 — 官方活動、平台公告
五角形 icon — IP 身分識別標記
翻牌留言：只有 IP 回覆時出現粉色高亮，未翻牌維持灰色靜默。粉色稀缺感讓「被看見」這件事視覺上非常清楚。
