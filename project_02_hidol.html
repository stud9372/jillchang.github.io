背景與核心洞察

2023 年，遊戲橘子決定從 beanfun! 出發，打造全新的粉絲社群平台。這不是舊產品的升級，是從零開始的建造——沒有前例，也沒有現成答案。

轉型初期，會議室裡最常聽到的一句話是「這個功能原來也有，要不要帶過來？」討論的重心不斷被舊產品的記憶拉走，而不是聚焦在新平台到底要解決什麼問題。

早期工作坊 → 需求金字塔梳理 → 策略方向對齊

我的第一步是把討論拉回核心：用需求金字塔把不同類型 IP 的用戶需求攤開，結合集團現有資源，找出哪種 IP 在短期內最有條件切入。策略有了依據，取捨才有辦法真正落地。

核心洞察

粉絲不只是想要「另一個追星 app」，他們真正想要的是一個懂我熱愛的地方——和同溫層的連結感、被 IP 看見的距離感、以及能把個人喜好化為身分認同的空間。

這個洞察成為 hidol 整體設計的起點。隨著方向收斂，設計團隊展開分工——我主導的範疇涵蓋創作者平台基礎建設（內容排程、粉絲團管理、數據分析）、即時互動體驗，以及整體 Icon 視覺系統的建立與落地。多條模組並行推進，每個決策都牽動彼此。

設計分工並行推進 → 多模組設計 → 視覺系統落地

取捨決策 · 架構盤點中的正式斷捨離

MVP 範疇收斂過程中，最關鍵的一個取捨來自舊產品線。轉型初期，團隊對舊產品的部分功能抱持「也許可以沿用」的心態，其中討論最多的是原有的展示品功能系統（SHOW）。隨著新平台的 IA 架構逐步清晰，我們一起盤點了每個模組與 hidol 核心定位的關係——最終，SHOW 功能正式從路線圖中移除：

捨棄
舊產品展示品功能（SHOW）
SHOW 是針對舊產品用戶行為設計的模組，邏輯與 hidol 以「粉絲社群互動」為核心的 IA 不相容。強行帶入會稀釋平台定位，也會增加用戶的認知負擔。架構盤點後正式移除，讓新平台的結構更純粹。
保留並簡化
周邊商品入口（串接集團電商）
周邊購買保留作為 IP 體驗的延伸入口，但不自建金流與物流——直接串接集團既有電商平台，免去重複建造的複雜度，設計端只需聚焦在粉絲從互動到購買的情境銜接。

MVP 功能架構：框線標示的區塊為第一版刻意延後或捨棄的範疇

視覺底色 · 讓 IP 成為唯一主角
核心設計觀

「平台本身是底色，最精彩的永遠是 IP 與粉絲之間的故事。」

這個設計觀定義了 hidol 整個視覺系統的方向：平台本身不能搶戲，要成為最好的承載容器，把 IP 與粉絲之間的情感連結放在最顯眼的位置。

具體落地在視覺決策上，就是選擇了深色系作為整體基調。深色介面本身低調沉穩，不干擾 IP 的主題色與圖像，讓每一個粉絲團都能在同一套框架下發展出截然不同的視覺風格。為了在深色背景上保持層次感又不顯笨重，我們的色板捨棄純白，改用多階透明度來構築視覺層次：

介面中的文字、底板、分隔線，全部來自同一個白色基礎色，以 95% / 90% / 80% / 70% 四個透明度區間進行區分。這讓整個介面的灰階過渡保持和諧，不同 IP 主題疊上來時，底層的灰度關係也不會失控。

這個決策的另一層考量是工程效率——單一基礎色搭配透明度，比維護多組靜態灰色值更容易保持一致性，也更容易讓不同工程師的實作結果對齊設計稿。

Alpha 色表：以透明度取代靜態灰階，統一介面層次

色彩語言 · IP 情感的視覺編碼

hidol 的介面裡存在三種視覺主體：IP 本身的品牌色、平台的官方行為、以及粉絲的互動行為。為了讓用戶在無須閱讀文字的情況下就能辨認脈絡，我們為每種主體制定了專屬的色彩語意。

粉絲團首頁：三層色彩語意在同一個頁面共存

粉色（#FF3B80）— IP 發文、心動互動
紫色（#7B5FE0）— 官方活動、平台公告
五角形 icon — IP 身分識別標記

其中最細膩的是「翻牌留言」的色彩邏輯。IP 貼文下的留言，只有 IP 主動回覆才會出現粉色高亮；沒被回應的留言維持灰色靜默。粉色在頁面中具有稀缺感——出現了，就代表被看見了。

翻牌留言：IP 回覆後粉色高亮，未翻牌維持灰色靜默

Icon System · HiDol 視覺語彙重塑

原有 Icon 風格較為單一、缺乏品牌記憶點。我們分析年輕世代愛用社群後，決定保留「線性風格」的清爽感，同時注入更具活力的品牌幾何語彙，服務 20–38 歲 Z 世代用戶，傳遞「酷、神秘、狂熱」的追星氛圍——輕量化視覺不搶戲，舞台永遠屬於創作者。

我負責的系統內 icon 範疇、slot web 元件以及介面：活動、探索

品牌光芒 Spark
融入象徵微光的紅點亮點元素，代表偶像發光的瞬間，讓 Icon 本身成為品牌情感的載體。
科技流線 Sleek
運用一筆畫線體的連貫性，呼應 Logo 中 "dol" 的幾何結構，營造科技感與俐落的視覺語調。
圓潤幾何 Balanced
將 hidol 幾何「方積」DNA 融入 Icon，優化圓角潤飾。在方正感（品牌個性）與圓潤感（社群溫度）之間取得平衡，每一個 Icon 既有辨識度又不失親近感。
上線成果 · 2024/07/16

2024 年 7 月 16 日，hidol 在 App Store 與 Google Play 同步上線。首版包含粉絲社群、IP 互動、創作者平台等核心模組；同年 12 月，AI 粉絲應用語音信功能上線，獲得社群正面回饋。

上線後收集的用戶問卷文字雲中，「懂我」、「有溫度」、「粉絲感」這些詞語高頻出現——與最初設計時的核心洞察直接呼應，驗證了「讓 IP 發光、平台退居底色」的設計方向。
